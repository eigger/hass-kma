# 문제 해결 가이드

기상청 APIhub 연동 구성요소(`hass-kma`) 사용 중 자주 발생하는 문제와 해결 방법입니다.

## 자주 묻는 질문 및 문제 해결

### 1. 설정 시 "인증키가 올바르지 않습니다" 오류

- [기상청 APIhub](https://apihub.kma.go.kr/) 포털에서 회원가입 및 발급받은 정식 인증키인지 확인하세요.
- 인증키 앞뒤에 공백 문자나 줄바꿈이 들어가지 않았는지 확인하세요.

### 2. 특정 "활용신청 필요" 진단 센서가 `off` 상태인 경우

- `binary_sensor.kma_activation_*` 진단 센서를 확인하세요.
- 특정 서비스(예: 자외선지수, 대기정체지수, 레이더, PM10 등)의 활용신청 센서가 `off`인 경우, [기상청 APIhub](https://apihub.kma.go.kr/)에 로그인하여 해당 API 서비스에 대한 활용신청을 추가로 진행해야 합니다.
- 활용신청 승인이 완료되면 다음 갱신 주기부터 자동으로 정상 조회되어 센서가 `on`으로 전환됩니다.

### 3. 꽃가루 및 계절성 지수 센서 상태가 "데이터 없음"인 경우

- 참나무, 소나무, 잡초류 꽃가루위험지수 등 일부 보건기상지수는 계절별 서비스 기간에만 제공됩니다:
  - 참나무/소나무 꽃가루: 3월 ~ 6월
  - 잡초류 꽃가루: 8월 ~ 10월
- 서비스 운영 기간 외에는 기상청 API에서 데이터를 제공하지 않으므로 정상적으로 `데이터 없음(unavailable)` 상태가 유지됩니다.

### 4. 호출 제한 및 에러 카운트 증가

- APIhub 호출 한도를 초과하거나 일시적인 네트워크 지연이 발생할 경우 `sensor.kma_error_count_*` 센서의 에러 카운트가 증가합니다.
- **설정 → 기기 및 서비스 → 기상청 APIhub → 구성**에서 데이터 갱신 주기를 늘리는 것을 권장합니다(기본값 10분, 5~180분 설정 가능).
